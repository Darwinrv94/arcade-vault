## Architecture / config notes

- App Router, root `app/` dir (no `src/`). Path alias `@/*` maps to repo root.
- `next.config.ts` enables `cacheComponents: true` (opt-in caching via `use cache`; dynamic data needs Suspense boundaries), `partialPrefetching: true`, and `experimental.agentFeedback`. See `cacheComponents.md` in the docs before writing data-fetching code.
- Tailwind v4 wired through Turbopack rule for `*.css` using `@tailwindcss/turbopack` loader (not PostCSS). Styles live in `app/globals.css`.
- Layout uses globally typed `LayoutProps<"/">` (generated route types) and `next/font/google` Geist fonts exposed as CSS vars `--font-geist-sans` / `--font-geist-mono`.
- TypeScript `strict: true`.
